# Polar Science Portal

## Development

Requires Node.js 20.19+ (or 22.12+) and npm.

```sh
npm i
npm run dev
```

Open the folder in VS Code, copy the supplied `env` file to `.env`, and then run the commands above in the integrated terminal. Use `npm run build` to create a production build and `npm run lint` to check the code.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
